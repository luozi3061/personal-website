# Linus · 个人介绍网站

一个以 **现代、简洁、玻璃拟态、浅蓝色主题** 为核心的个人介绍网站。

本项目由 **Linus × ChatGPT** 共同开发与迭代。

---

## 一、当前版本功能总览

### 1. 首页与个人信息
- 个人介绍主页
- 现代化顶部导航栏
- 中央个人介绍区域
- 头像展示
- 学生 / Developer / Photographer 等个人身份信息展示
- 中国 / China 位置标识
- 响应式布局

### 2. 深色 / 浅色模式
- 默认支持跟随系统主题
- 支持手动切换深色 / 浅色模式
- 页面会根据系统 `prefers-color-scheme` 自动适配
- Projects、Skills、联系方式等区域均支持浅色模式
- 浏览器 `theme-color` 会随主题变化

### 3. 手机端适配
- 根据浏览器 UA / 屏幕环境自动进入移动端布局
- 移动端导航、卡片、社交平台区域均进行重新排版
- 社交图标支持小屏幕自适应
- Games 卡片和其他内容在手机端自动调整列数

### 4. Skills
当前包含：

- **Python**：使用 Python 官方风格的蟒蛇图标
- Creative
- Games

Games 当前包含：

- 原神（国服图标）
- 崩坏：星穹铁道
- 绝区零
- 鸣潮
- 明日方舟：终末地
- 异环

Games 卡片在桌面端使用更宽的布局，以充分利用右侧空间；游戏图标统一使用本地资源。

### 5. Projects
当前保留 Photo 项目卡片：

- `PHOTO ↗` 点击后直接跳转微信公众号入口
- 不再提供独立的照片页面
- 项目卡片保持原有设计风格

### 6. 社交媒体
社交平台采用：

**圆形图标 + 图标下方名称** 的形式。

国际平台使用英文名称，例如：

- GitHub
- YouTube
- X
- Threads
- Facebook
- Instagram
- TikTok

国内平台使用中文名称，例如：

- 哔哩哔哩
- 微博
- 抖音
- 微信公众号
- 微信视频号

所有社交平台整体左对齐，并与 Email 区域的文字基线保持一致。

### 7. 邮箱
支持：

- Outlook
- Gmail
- iCloud

邮箱同样采用 **圆形图标 + 名称** 的形式。

其中：

- Outlook 使用主题色邮件图标
- iCloud 使用云朵图标
- Gmail 使用对应品牌图标
- 邮箱之间的间距进行了压缩，使整体更加紧凑

### 8. Favicon / 浏览器标签栏图标
- 浏览器标签栏使用个人头像作为网站小图标
- 同时提供 `favicon.ico`、`favicon.png` 和 Apple Touch Icon
- 移动设备添加了对应的触控图标

### 9. README 与项目结构
项目根目录保留本说明文件 `README.md`。

当前目录结构大致为：

```text
personal-intro-site-games-icons/
├── index.html
├── styles.css
├── script.js
├── README.md
├── avatar.png
├── favicon.png
├── favicon.ico
├── apple-touch-icon.png
└── game-icons/
    ├── genshin.jpg
    ├── hsr.jpg
    ├── zzz.jpg
    ├── wuthering.jpg
    ├── endfield.jpg
    └── nte.webp
```

> 当前版本已经移除旧的 `photos/` 文件夹和独立照片页面相关资源。

# 二、项目完整改动时间线

下面按照本网站从最初版本到当前版本的实际迭代顺序整理。

## 阶段 01：建立个人介绍网站

最初目标是制作一个个人介绍网站，而不是普通模板站。

完成内容：

- 建立个人主页
- 现代化 UI
- 顶部导航栏
- 中央个人简介卡片
- 深色玻璃拟态视觉风格
- 背景图和玻璃效果
- 3D 卡片鼠标倾斜效果
- 博客 / 项目等基础页面结构

## 阶段 02：加入深色模式与动态体验

网站开始从静态页面向完整个人主页发展。

加入：

- 深色主题
- 加载动画
- 移动端菜单
- 卡片交互
- 页面整合
- 更现代的动画和视觉效果

## 阶段 03：建立项目展示体系

项目区域开始成为网站的重要组成部分。

后来将原本的项目内容改造成个人摄影方向，并建立 Photo 项目入口。

## 阶段 04：加入社交媒体体系

联系方式从简单邮箱扩展为完整社交平台区域。

先后加入并调整：

- GitHub
- Bilibili / 哔哩哔哩
- YouTube
- 微博
- X
- Threads
- Facebook
- Instagram
- 抖音
- TikTok
- Email

同时明确不使用微信 / QQ 作为普通聊天联系方式，后续又根据个人主页定位加入公众号和视频号入口。

## 阶段 05：加入浅色模式

网站从单一深色模式升级为深浅双主题。

完成：

- 浅色模式
- 深色模式
- 主题切换按钮
- 浅色玻璃卡片
- 浅色背景与阴影
- 主题色系统

之后又进一步改为默认根据系统主题自动选择。

## 阶段 06：建立 Favicon 与品牌小图标体系

开始专门优化浏览器标签栏的小图标与平台图标。

经历了多轮调整：

- 站点 Favicon
- Apple / 头像等不同尝试
- 最终将浏览器标签栏图标改为个人头像
- 增加 favicon.ico
- 增加 favicon.png
- 增加 Apple Touch Icon

同时确认：

> 浏览器标签栏的小图标和页面中的社交平台图标是两套独立元素。

## 阶段 07：社交平台图标视觉统一

社交平台从文字链接逐步升级为图标化入口。

完成：

- 圆形图标
- 浅蓝色主题
- 图标统一尺寸
- 图标下显示平台名称
- 社交平台整体对齐
- 中文平台使用中文名称
- 海外平台使用英文名称

期间反复修正了：

- Outlook 图标
- iCloud 图标
- TikTok / 抖音图标
- 微信公众号图标
- 微信视频号图标

最终统一为网站当前的视觉风格。

## 阶段 08：邮箱系统完善

# 三、日常修改方法

## 修改个人姓名 / 简介

打开：

```text
index.html
```

搜索首页中的个人信息文字即可修改。

## 修改社交平台链接

同样在：

```text
index.html
```

搜索对应平台名称，然后修改 `href`。

例如：

```html
<a href="你的链接">GitHub</a>
```

## 修改微信公众号链接

找到 Photo 项目中的：

```text
https://mp.weixin.qq.com/
```

将其替换为你的真实公众号入口地址。

## 修改游戏图标

游戏图标全部放在：

```text
game-icons/
```

替换对应文件后，再保持 `index.html` 中的文件名一致即可。

## 修改颜色

主要样式集中在：

```text
styles.css
```

网站核心浅蓝色主题可以在 CSS 变量中统一修改。
